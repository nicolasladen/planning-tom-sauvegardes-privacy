Planning Tom Sauvegardes

Politique de confidentialité

Dernière mise à jour : 26 octobre 2026

Planning Tom Sauvegardes est un outil personnel de sauvegarde vers le compte Google Drive de son utilisateur. Il utilise l’API Google Drive, rclone et, lorsque les workflows sont activés, GitHub Actions.

Données Google consultées

Avec l’autorisation de l’utilisateur, l’outil accède aux fichiers et dossiers Google Drive nécessaires aux sauvegardes configurées. Selon cette configuration, il peut lister, lire, créer, mettre à jour ou supprimer des fichiers.

Utilisation, stockage et partage

Les fichiers sont transférés entre la source de sauvegarde et le compte Google Drive de l’utilisateur conformément à sa configuration rclone et aux workflows activés. Les identifiants OAuth sont conservés par l’utilisateur dans son environnement local et, s’il choisit GitHub Actions, dans les secrets GitHub Actions de son dépôt privé. Aucun identifiant OAuth ni secret n’est publié sur ce site.

L’outil ne vend ni ne partage les données Google avec des tiers. Google traite les données nécessaires au fonctionnement de Drive. GitHub traite les données nécessaires à l’exécution des workflows configurés par l’utilisateur. Cette page n’utilise pas de publicité ni d’outil d’analyse; GitHub peut enregistrer l’adresse IP des visiteurs à des fins de sécurité conformément à sa politique de confidentialité.

Conservation et contrôle

Les sauvegardes restent dans Google Drive jusqu’à ce que l’utilisateur les supprime ou modifie leur rétention. L’utilisateur peut révoquer l’accès de l’application dans les paramètres de sécurité de son compte Google, supprimer les secrets GitHub Actions ou désactiver les workflows concernés.

Contact

Pour toute question, utilisez l’adresse de contact du développeur indiquée sur l’écran d’autorisation OAuth de Google.

Outil personnel, non affilié à Google ou GitHub.
